Connection & configuration

Configure Nintendo presence, save your settings to Cloudflare KV, and authorize your Discord App.

Saving to KV: the Worker only accepts changes from requests carrying your CODYRPC_TOKEN secret, so paste it into the admin token field once. It is kept only in this browser and is never included in exported settings.

Discord App integration note: after you authorize, the Worker keeps your Discord token in KV and updates your presence every minute on a cron schedule, even with every browser closed. In the Discord Developer Portal, make sure your exact Redirect URI is added and that the app is set as a Public Client (OAuth2 page). Save your admin token above before authorizing.
