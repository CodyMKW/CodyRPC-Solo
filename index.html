 CodyRPC Cloudflare Worker Setup Guide

        
Follow these simple steps to host the Cloudflare Worker backend and set up Discord Application permissions.

      


      

        
        
        

          
1

          
Discord Application Setup

          

            Go to the Discord Developer Portal and create a new Application.
          

          
    
            
  • Copy your Application Client ID.
    • 
            
  • In OAuth2 Settings, add scopes: activities.write and rpc.
    • 
            
  • Enable Embedded App Activity if prompted.
    • 
          

        


        
        

          
2

          
Deploy Cloudflare Worker

          

            Log in to your Cloudflare Dashboard and navigate to Workers & Pages.
          

          
    
            
  • Create a new HTTP Worker service (e.g. codyrpc-worker).
    • 
            
  • Click Edit Code and paste the complete worker.js provided in the Worker Script tab.
    • 
            
  • Deploy the worker and copy your *.workers.dev URL.
    • 
          

        


        
        

          
3

          
Connect & Sync

          

            Finalize connection between dashboard and worker.
          

          
    
            
  • Enter your NSA ID and Friend Code in the Settings form.
    • 
            
  • Optionally provide Bluesky handle & App Password to turn on automatic feed posts.
    • 
            
  • Your rich presence will automatically sync whenever you're online on your Switch!
    • 
          

        


      


      

        
        

          Pro Tip: Discord `activities.write` Scopes
          Because Discord's rich presence API relies on OAuth2 tokens or local RPC pipes, Cloudflare Workers can dispatch user activity events to Discord's gateway directly using user tokens or Discord Activity sessions authorized with activities.write.
